Nomenclature of Organic Compounds

Every organic compound's name is built from two parts: a prefix that tells you how many carbon atoms it has, and a suffix that tells you what kind of compound it is. Build a few yourself below and the pattern will click fast.

Carbon-count prefixes

The first part of the name always tells you how many carbon atoms are in the chain.

Meth-1 · Eth-2 · Prop-3 · But-4

Bond-type suffixes

These endings describe the bonds between carbon atoms in a plain hydrocarbon chain.

-ane single · -ene double · -yne triple

Functional group suffixes

These endings replace the hydrocarbon suffix entirely when a functional group is present.

-ol alcohol (−OH) · -oic acid (−COOH)

The naming rule

Every simple organic name you'll be asked for at this level follows the same pattern.

Name = Prefix + Suffix
